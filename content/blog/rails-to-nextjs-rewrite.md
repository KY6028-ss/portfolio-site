---
title: ポートフォリオサイトを Rails から Next.js に書き直した話
---

このサイト、もともとは Rails 8 + Python (FastAPI) の2サービス構成でした。Gemini 2.5 Flash を使った RAG チャットを載せて、自宅の Raspberry Pi 5 + Cloudflare Tunnel でセルフホスティングする予定で作っていました。

それを先日、Next.js + TypeScript の単一アプリに全面的に書き直しました。理由を残しておきます。

## 公開できないまま時間が過ぎていた

一番大きいのはこれです。2サービス構成は Docker や Kamal 2 前提で運用が重く、デプロイは未実施のままずっと公開が遅れていました。

サーバーも「VPS を借りるか、自宅の Raspberry Pi 5 を使うか」で迷っていたのですが、どちらも当初の想定より工数も費用もだいぶかかりそうで。凝った構成を組み上げるより「とにかく公開する」を目標にしようと切り替えました。Next.js + Vercel なら無料でゼロコンフィグで公開できるので、これが決め手です。

## AI チャットを載せる必要がなくなった

もともとの目玉機能は、私のプロフィールに答えてくれる RAG チャットでした。ただ 2026年5月にブラウザのサイドパネルから Gemini が直接使えるようになって、「サイトに独自チャットを埋め込む意味あるかな？」と考え直しました。

公開サイトで API キーを持つサーバーを動かし続ける運用コストやキー管理の心配もあったので、AI チャットは一旦スコープ外に。おかげでサイト全体が静的生成だけで完結するようになりました。

## このサイトの位置づけも変えた

書き直しに合わせて、サイトの役割も整理しました。

- 整った成果物や記事は **Zenn** で公開する
- このサイトは**個人ナレッジや日記みたいに、ふだんやっていることをのほほんと書いていく場所**にする

この位置づけなら DB も管理画面も要らなくて、Markdown ファイルを置くだけのシンプルな構成で十分です。記事を書く → push する → 公開される、くらいの気軽さでやっていきます。

## 移行してどうなったか

- リポジトリはルート直下の単一 Next.js アプリに
- コンテンツは `content/` の Markdown 管理(DB 廃止)
- 全ページ SSG で、Vercel に置くだけで公開できる

旧構成で学んだこと(Rails 8、FastAPI、LangChain での RAG 実装)は無駄ではなくて、それはそれで経験として残しつつ、サイトは身軽になりました。
