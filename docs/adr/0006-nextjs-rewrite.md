# ADR-006: Next.js (TypeScript) への全面書き直し

- ステータス: Accepted
- 日付: 2026-07-05

## コンテキスト

サイトは Rails 8 モノリス + Python FastAPI（RAG チャット）の2サービス構成だった（[ADR-003](0003-final-stack.md) / [ADR-004](0004-rag-ai-service.md)）。移行を決めた理由は以下のとおり（2026-07-05 オーナーヒアリングより）。

### 運用・デプロイの重さと、公開の遅れ

- 2サービス構成は Docker / Kamal 2 前提で運用が重く、デプロイは未実施のまま公開が遅れ続けていた
- デプロイ先も「VPS を借りる」か「自宅 Raspberry Pi 5 をサーバーにする」かで迷っており、どちらも当初想定より工数・費用が大幅にかかる見込みだった
- そこで凝った構成よりも**「とにかく公開する」ことを最優先の目標**に切り替えた。Vercel なら無料・ゼロコンフィグで公開でき、これが Next.js 選定の決め手でもある

### AI チャット（RAG）を載せる必要性の低下

- 2026年5月2日にブラウザのサイドパネルから Gemini が直接使えるようになり、**サイト独自に AI チャットを搭載する意義が薄れた**
- 公開サイトで API キーを持つサーバーを動かし続ける運用コスト・キー管理の懸念もあった

### サイトの位置づけの変化

- 整った成果物・記事は **Zenn** で公開していく
- 本サイトは**個人ナレッジや日記のように、ふだんやっていることを気軽に書いていく場所**とする
- この位置づけなら DB や管理画面は不要で、Markdown ファイル + 静的生成で十分

また実装面でも、コンテンツは DB（SQLite）管理ながら管理画面はなく中身はシードデータ相当のみ、クライアントサイド JS はほぼゼロ（Hotwire は宣言のみで未使用）と、モノリス構成の恩恵をほぼ受けていなかった。

## 決定

- **Next.js（App Router）+ TypeScript + Tailwind CSS v4** に全面書き直し
- コンテンツは **リポジトリ内の Markdown ファイル**（`content/`、frontmatter 付き）で管理し、DB を廃止
- 全ページ **SSG**（`published` 相当のフィルタはビルド時に評価）
- **AI チャット機能は一旦スコープ外**とし、`python_ai/` ごと削除（将来は Next.js の Route Handler + Vercel AI SDK 等で再実装できる）
- デプロイ先は **Vercel**（Kamal 2 構成は廃止）
- `rails_app/`・`docker-compose.yml`・スキャフォールド用スクリプト群を削除

## 結果

- リポジトリはルート直下の単一 Next.js アプリになった
- 旧デザインは CSS 変数トークンごと Tailwind の `@theme` に移植（ダークモード含む）
- コンテンツの追加は Markdown ファイルの追加のみで完結し、Git で履歴管理できる
- 旧スタック（ADR-001〜005 の対象）はこの ADR をもって廃止。経緯の記録として ADR は残す
