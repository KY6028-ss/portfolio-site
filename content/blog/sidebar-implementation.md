このサイトにタブ型ナビゲーションと「最近の更新」サイドバーを追加しました。
実装はClaude Code(Claude Fable 5)に任せて、私は日本語で要望を伝えただけです。
この記事では、実際にどんな手順で進んだのかを記録として残しておきます。

## やりたかったこと

- ナビゲーションのリンクがただの文字で、クリックできるものだと分かりにくい
- 左側にサイドバーを置いて、サイトの更新（ブログ・お知らせ・実績）を新しい順に並べて、各記事へ直接飛べるようにしたい

## Claude Fableに出した指示

実際に出した指示はほぼこれだけです。

> 現状ほかのタブをクリックできるかわかりにくい状況なので、視覚的にほかのタブがあることをわかるようにしてください。
> また、左側にサイドバーを追加してポートフォリオサイトの更新順毎もならべてサイトに行けるようにしてください。

## Fableが実際にやった手順

1. **既存コードの確認** — いきなり書き始めずに、ヘッダーやコンテンツ読み込み処理、CSSのデザイントークンを読んで構成を把握していました
2. **実装方針の提示** — 「タブ型ナビ + 現在ページのハイライト」「全コンテンツを日付順に統合したサイドバー」という方針を先に説明してから着手
3. **データ層の追加** — コンテンツローダーに `getRecentUpdates()` という関数を追加。ブログ・お知らせ・実績を公開日時の新しい順に統合して、未公開のものは除外する作りです
4. **UIの実装** — タブは現在ページだけ色が変わるようにし（`aria-current` というアクセシビリティ属性も付いていました）、サイドバーは画面が広いときだけ表示・スクロールに追従する形に。スマホで崩れないように非表示にする、みたいな指示していない部分も考慮されていました
5. **テストの追加と検証** — 新しい関数のテストを自分で書いて実行（20件パス）、lintとビルドも確認
6. **動作確認** — 開発環境にブラウザが無かったので、本番サーバーを起動してHTMLを直接取得し、「アクティブなタブに属性が付いているか」「サイドバーの並び順が正しいか」を確認していました。スクリーンショットが撮れないなりの検証方法を勝手に考えていたのが面白かったです

## 使ってみて

要望は2文だけだったのに、モバイル対応・アクセシビリティ・テストまで含めて実装されました。
最後に「ブラウザが無いのでスクリーンショットは撮れていません。npm run devで見た目をご確認ください」とFableより出力されました。
知見が足りないのですが、MCPサーバーと接続させることで、ブラウザの表示を確認できるようになるのでしょうか...

また、いつも通りですが、私自身がコードを読み切れていません...
今やっているデータサイエンス・機械学習部分の理解がひと段落したら後日コードを読み返して理解しようと思います。
