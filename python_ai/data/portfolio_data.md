# ポートフォリオ：職務経歴およびスキルセット

## 自己紹介
私はRuby on RailsとPythonを用いたWebバックエンド開発が得意なシニアソフトウェアエンジニアです。
近年はバックエンド開発にとどまらず、FastAPIを用いたマイクロサービスアーキテクチャの構築や、LLM（大規模言語モデル）を活用したAI機能のプロダクトへの組み込みに注力しています。
趣味は個人開発と、常に進化する新しい技術のキャッチアップです。

- **AI・機械学習**: LangChain, LlamaIndex, OpenAI API, Google Gemini API, RAGアーキテクチャ構築

## 職務経歴・実績
### 1. Eコマースサイトの決済基盤リプレイス
- **概要**: 老朽化したモノリスアーキテクチャから、マイクロサービスへの移行に伴う決済基盤のリプレイスを担当。
- **技術スタック**: Ruby on Rails, PostgreSQL, AWS ECS
- **成果**: 決済処理のレイテンシを30%削減し、システムの可用性を99.99%に向上。また、 Stripe API への移行を主導し、運用コストの削減に貢献しました。

### 2. 社内ナレッジ共有AIアシスタントの構築
- **概要**: 散在する社内ドキュメントを横断検索・要約するAIアシスタントを開発。
- **技術スタック**: Python, FastAPI, LangChain, FAISS, OpenAI API
- **成果**: 従業員が目的のドキュメントにアクセスする時間を平均1日あたり30分削減。RAGを活用し、ハルシネーション（幻覚）を最小限に抑えた高精度な回答システムを実現しました。

### 3. 個人開発ポートフォリオサイト
- **概要**: 自身の経歴やスキルを公開するためのインタラクティブなWebサイト。
- **技術スタック**: FastAPI, React, LangChain
- **特徴**: RAGを組み込んだチャットボットを実装し、サイト訪問者が自然言語で私のスキルや実績について質問できるようにしました。
