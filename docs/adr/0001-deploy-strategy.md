# ADR-001: デプロイ戦略

- ステータス: Accepted（後続の [ADR-003](0003-final-stack.md) で Kamal 2 へ移行）
- 日付: プロジェクト初期

## コンテキスト
個人ポートフォリオサイトを低コストかつ短時間で公開する手段が必要だった。

## 決定
初期デプロイ先として Rails + Fly.io を採用する。将来的に Kamal 2 への移行を検討する。

## 結果
- 早期に公開可能。
- 後に [ADR-003](0003-final-stack.md) で Kamal 2 を正式採用し、ホストは VPS（Hetzner）または Fly.io とした。
